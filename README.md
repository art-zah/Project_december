Проект "Генератор расписания"

суть: пользователь входит в аккаунт, добавляет информацию о преподавателях, группах, ограничениях преподавателей и т.д., после чего нажимает кнопку "создать расписание", сервер анализирует все параметры введенные пользователем и выдает корректное расписание

запуск: требуется войти в виртуальное окружение в редакторе кода, скачать зависимости (команда в терминале: "pip install -r requirements.txt", на MacOS - pip3), настроить файл .env (добавить свои значения на DATABASE_URL и SECRET_KEY), запустить main.py (команда в терминале: "python main.py"), после чего зайти в браузер и по ссылке http://127.0.0.1:8000 можно посмотреть проект.

результаты: на данном этапе проект готов на 50%, полностью реализована аутентификация; показ главной страницы; структура БД; накиданы стили адаптивной верстки; активно ведется работа над папкой с модулями для генерации (services).

осталось: добавить все страницы, для ввода данных от пользователя(они будут похожи друг на друга, единственное с разными проверками на корректность данных) и удобного просмотра своих данных в виде таблиц; страницу с генерацией расписания.
вполне возможно, что будет добавлено куча мелочей, по типу уведомление о успешной авторизации, вход по реальной почте с отправкой кода подтверждения.
