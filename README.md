Проект "Генератор расписания"

суть: веб-приложение, предназначенное для автоматизированного составления учебного расписания. Пользователь входит в аккаунт, добавляет информацию о преподавателях, группах, ограничениях преподавателей и т.д., после чего нажимает кнопку "создать расписание", сервер анализирует все параметры введенные пользователем и выдает корректное расписание.

запуск: требуется войти в виртуальное окружение в редакторе кода, скачать зависимости (команда в терминале: "pip install -r requirements.txt", на MacOS - pip3), настроить файл .env (добавить свои значения на DATABASE_URL и SECRET_KEY), запустить main.py (команда в терминале: "python main.py"), после чего зайти в браузер и по ссылке http://127.0.0.1:8000 можно посмотреть проект.

результаты: проект полностью готов и функционирует, полностью реализованы: аутентификация; показ главной страницы; просмотр, добавление, редактирование и удаление (CRUD) данных от пользователя как на backend так и на frontend (classrooms, teachers и т.д.); непосредственно сам модуль генерации; уведомление о успешных действиях пользователя и показ ошибок; логи ошибок серверной части; структура БД; стили адаптивной верстки.
